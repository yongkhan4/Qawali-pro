Qawwali Live - Android/Chrome MVP
1. Unzip this folder.
2. For easiest testing, open index.html in a modern browser that allows microphone access, preferably Chrome over HTTPS or localhost.
3. On Android, microphone access is usually blocked for file:// pages. For a quick test, upload the folder to any HTTPS static host, or run a local server on a computer and open it from the phone.
4. Press START LIVE, grant mic permission, choose Sa, and sing.
5. The harmonium follower is synthesized locally. Tabla and drone are also synthesized so this build has no external dependencies.

Important: this is a prototype, not a guaranteed professional stage instrument. For a real performance build, the next upgrade should replace synthesized tabla/harmonium with high-quality multisamples and add latency calibration, feedback protection, MIDI/Bluetooth routing, and an Android native audio engine.
